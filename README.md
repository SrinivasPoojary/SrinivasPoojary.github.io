## Featured Projects

### 1. [AdventureWorks Executive Sales Intelligence & NEXUS IQ](https://srinivaspoojary.github.io/adventureworks-sales-intelligence/)
* **Stack:** Power BI, DAX, Star Schema, HTML5/Tailwind CSS
* **Overview:** Built an enterprise B2C analytics reporting suite analyzing ₹29.36M in revenue across 27.66K orders. Formulated 11 explicit DAX measures using an independent contiguous calendar table.
* **Key Finding:** Identified catalog margin asymmetry—Bikes drive 96.4% of top-line revenue at 41% margin, while Accessories generate 63% margin across 36K units.
* **Interactive Tool:** Deployed the **NEXUS IQ** scenario simulator to model cross-sell accessory attach rates and manufacturing cost shifts.
* **Links:** [Live Demo](https://srinivaspoojary.github.io/adventureworks-sales-intelligence/) | [GitHub Repo](https://github.com/SrinivasPoojary/adventureworks-sales-intelligence)
